# TBS Libraries Reference — v1.1.0 Updates

New libraries: `Lib.Security` (AES, HMAC SHA-256/SHA-512/MD5, hash, signatures, Ed25519, payment webhook verification), `Lib.TeleGifts`, expanded `Lib.Random` (hex, bytes, uuid, password, choice, sample, shuffle, weightedChoice, boolean, range, gaussian). Updated `Lib.EVM` (fetchBalance, fetchTokenBalance) and `Lib.TON` (get_jetton_wallet_address, register_ton_connect_wallet).
