# TBS Libraries Reference — v1.1.0 Updates
This page is a pointer. The v1.1.0 library additions are now documented in full, with complete method signatures, parameters, return values, and examples, on their canonical reference pages:
\* \*\*`Lib.Security`\*\* (HMAC signing/verification, Ed25519, payment gateway webhook verification, AES encryption, SHA-256/SHA-512/MD5 hashing) — see [TBS Libraries Reference](https://help.telebotstudio.com/tbs-libraries).
\* \*\*`Lib.TeleGifts`\*\* (gift catalog, sending, history, stats, settings) — see [TBS Libraries Reference](https://help.telebotstudio.com/tbs-libraries).
\* \*\*Expanded `Lib.Random`\*\* (hex, bytes, uuid, password, choice, sample, shuffle, weightedChoice, boolean, range, gaussian) — see [TBS Libraries Reference](https://help.telebotstudio.com/tbs-libraries).
\* \*\*`Lib.PIL` and `Lib.CV`\*\* (image editing and computer vision) — see [TBS Media Libraries (PIL & CV) Documentation](https://help.telebotstudio.com/tbs-media-libraries-pil-and-cv-documentation).
\* \*\*`Lib.EVM.fetchBalance` and `Lib.EVM.fetchTokenBalance`\*\* — see [EVM Library Documentation](https://help.telebotstudio.com/evm-library-documentation).
\* \*\*`Lib.TON.get\_jetton\_wallet\_address` and `Lib.TON.register\_ton\_connect\_wallet`\*\* — see [TON Library Documentation](https://help.telebotstudio.com/ton-library-documentation).
For the complete list of everything shipped in v1.1.0, see [TeleBot Studio v1.1.0 — Media Libraries, Gifts, Webhooks & More](https://help.telebotstudio.com/telebot-studio-v1.1.0-media-libraries-gifts-webhooks-and-more).
