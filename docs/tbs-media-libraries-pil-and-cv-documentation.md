# TBS Media Libraries (PIL & CV) Documentation

Built-in libraries: `Lib.PIL` (Pillow image editing) and `Lib.CV` (OpenCV computer vision). No imports needed.

Includes openFromBytes, toBytes, resize, crop, rotate, flip, adjustBrightness, applyFilter, drawText, drawRectangle, drawCircle, drawLine, createGradient, addWatermark, detectFaces, drawFaces, threshold, adaptiveThreshold, detectEdges, perspectiveTransform, blendImages.
